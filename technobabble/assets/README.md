# Technobabble icon

Created with the built-in image_gen tool for this application. The PNG is the master; ICO and ICNS are platform icon containers, and the 256-pixel RGBA file is embedded in the native window. No image service is required at runtime.

Generation prompt:
Use case: logo-brand. Create a catchy premium desktop app icon for Technobabble, an offline voice-following teleprompter. A bold speech bubble fused with a simple teleprompter screen and three clear script strokes, with a playful forward cue. Single centered symbol, crisp silhouette, polished dimensional finish, strong contrast, readable at small dock sizes. No words or letters, no mockup, no extra objects. Square app icon with rounded tile and transparent space outside the tile.

The project source is in the technobabble directory. Product binaries and archives use technobabble. TECHNOBABBLE_HOME is supported; the previous RUST_PROMPTER_HOME override remains compatible.

## Bold script font

`DejaVuSans-Bold.ttf` supplies bold emphasis for Word imports on every platform. It and `DejaVu-LICENSE.txt` were retained from the original QPrompt source font assets. The license is included in portable packages.
